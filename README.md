# Arcade Games

A collection of 5 classic arcade games built with vanilla HTML, CSS, and JavaScript. Each game is a standalone file that can be opened directly in a browser.

## Games

- **arcadeindex.html** - Main menu linking to all games
- **carracer.html** - Dodge obstacles and collect coins
- **blockmatch.html** - Stack falling blocks (Tetris-style)
- **flyingaeroplane.html** - Navigate through pipe gaps
- **snake.html** - Eat food and grow without hitting yourself
- **balldrop.html** - Bounce a ball to collect coins with a paddle

## How to Play

Open `arcadeindex.html` in any browser, or open any game file directly.

## Controls

| Game | Controls |
|------|----------|
| Car Racer | A/D keys or swipe |
| Block Match | Arrow keys |
| Flying Aeroplane | W/Space/Up or tap |
| Snake | Arrow keys |
| Ball Drop | Left/Right arrow keys |
